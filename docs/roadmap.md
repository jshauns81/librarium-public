# Development roadmap

Librarium brings catalogue and library evidence into a read-only reading room. [Product scope](../PRODUCT.md) and [architecture](architecture.md) describe its direction and ownership boundaries.

| Goal | Acceptance |
|---|---|
| Release foundation | Reproducible source and container checks, immutable image digests and a recovery procedure. |
| Isolated beta | Separate state and credentials, reviewed activation, and a representative authenticated session. |
| Daily reading | Accessible browsing and reading, source-bound observations, and verified upgrade and restore. |
| Candidate inspection | Independent source identity, explicit provenance and bounded validation without changing original files. |

Follow the [release policy](releases.md) for beta acceptance and stable promotion. The [decision record](decisions.md) describes the move away from EPUB repair in L091.
