Librarium reads and checks books. Open a book from the library to read it or inspect its metadata, EPUB structure and validation findings. New inspections show what the source contains, including headings, navigation and broken targets. Earlier reports and job history remain readable.

This release retires EPUB correction and delivery jobs. Before upgrading an existing installation, stop all earlier web, worker and delivery processes, then count unfinished retired jobs and delivery receipts. Preserve the database and matching artifacts together and verify a restore on an isolated copy. After upgrading, check existing reports and job history, open a book, and run a supported inspection.

The release manifest identifies the tested Linux amd64 application and optional source-browser images by digest. Both packages require authorized GHCR access. The stack archive contains matching Compose files and browser sandbox assets. File processing requires the target kernel and storage checks described in the release guide. Installing the beta is a separate operation.
