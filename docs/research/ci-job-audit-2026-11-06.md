# CI job coverage

## Script inventory including scripts not invoked by a workflow

Source checks cover Python and frontend behavior, dependency consistency and privacy. Container acceptance tests the built image and its recovery behavior. The populated-upgrade rehearsal checks schema and data compatibility. Writer acceptance exercises the isolated native boundary.

Use the [CI contract](../ci.md) for triggers, required results and runner isolation. Compare equivalent workloads when changing job selection. Keep serial proofs that share process state or fixed ports.
