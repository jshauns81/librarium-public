# Research evidence

Keep bounded, dated technical investigations here: question, source provenance,
primary citations, findings, uncertainty, tradeoffs and recommendation. Link to
canonical product/decision/status owners. Environment inventories and operational
acceptance evidence belong in [private context](../agent-environment.md).
Do not publish transcripts, personal information or actual-library observations.

[Architecture](../architecture.md) owns the assessment scope. The
[first-slice assessment](first-slice-2026-10-24.md) records technical alternatives
and the provisional experiment choice; verify current implementation in source.
