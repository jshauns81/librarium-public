# Codex workspace guide

Read [AGENTS.md](../AGENTS.md) and follow its shared startup sequence. Verify actual
host, checkout, branch/commit, remotes and local changes. Provider-specific guidance
never replaces shared product contracts.

Resolve installed skills through the active client, checking versions and managed
hashes privately. Preserve the managed ECC selection and native plugins; do not
change global settings or install a whole suite as a setup shortcut.
Load the current operational handoff through [private context](../docs/agent-environment.md).
Keep client configuration, personal paths and service endpoints outside GitHub.
Use active harness delegation tools, serialize shared-file edits, and record
status updates by adding a new file under `docs/status/` rather than editing
`docs/status.md` or another PR's entry.
