# Logos

The supplied **Librarium A** family (concept A, ornate sigil): emblem, outlined wordmark, horizontal and stacked lockups, and the small and micro drawings. Byte-for-byte copies of `images/brand/librarium-a/`.

These files carry their supplied ivory `#e8e0cc` and brass `#be9763` as fallbacks, so as images they render in the default brand colours on a dark ground. To recolour with a theme, use the geometry-only sprite `brand/librarium-symbols.svg` (`#emblem`, `#small`, `#wordmark`) through `<svg><use>` and set `--librarium-ink`, `--librarium-accent` and `--librarium-wordmark` from the brand roles.

Use the small drawing at masthead size (about 48px), the emblem for 128px decoration and empty states, the micro drawing only for favicons. Keep aspect ratios and transparent openings; never retrace or approximate.
