# Provenance

A definition list of where a record came from: source, identifiers, snapshot, digests and times.

Source: `.provenance` and `.hash` in `style.css`; `LibraryBookPane.tsx`, `JobProgress.tsx`, Catalogue detail.

`small` size; terms in `muted`, values in `ink`. One column on phones, a 105px term column from 620px. Digests and fingerprints use `hash` (mono 0.75rem) and wrap anywhere. Usually lives inside a **Disclosures** group (`Record details`, `Review record`). Show exact values; never abbreviate a digest without also exposing the full one.

The consumer provides term and value pairs.
