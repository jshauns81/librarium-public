# EmptyState

First-run and not-connected guidance: the detailed emblem, a Literata heading, what the product does and does not do, and one action.

Source: `.empty`, `.first-run`, `.connection-details` in `style.css`; `App.tsx`, `Library.tsx`.

The emblem is 6rem above the copy on phones and a 128px column beside it from 620px; the heading is `first-run` (Literata 1.8rem, balanced); paragraphs are `muted` at up to 52ch. One `primary` action, if any. Its claims follow **UX standards**. Smaller empty results (no matches) use `.empty` alone with `muted` copy at 50ch.

The consumer provides the heading, the explanation and the action.
